# 📱 Compatible Podcast Clients

Podhound is compatible with any podcast player that supports the **gPodder API v2** protocol.

---

### 📱 AntennaPod (Android)
**AntennaPod** is an open-source, feature-rich podcast manager for Android with built-in gPodder API v2 support.

* **Platform:** Android
* **License:** Open Source (GPLv3)
* **Downloads:** [Google Play](https://play.google.com/store/apps/details?id=de.danoeh.antennapod) | [F-Droid](https://f-droid.org/packages/de.danoeh.antennapod/) | [Website](https://antennapod.org/)
* **Setup Guide:** See our [AntennaPod Setup Guide](../setup/).

---

### 💻 gPodder Desktop
The original cross-platform podcast aggregator.

* **Platform:** Windows, macOS, Linux
* **License:** Open Source (GPLv3)
* **Downloads:** [gPodder Releases](https://gpodder.github.io/)
* **Setup:** In gPodder preferences, choose **gPodder.net**, click **Advanced**, and set the Custom Server URL to your Podhound server.

---

### 🐧 Kasts (KDE / Linux)
A modern podcast player for Linux desktop and mobile devices built with Kirigami.

* **Platform:** Linux (Flatpak / Arch / Fedora / Ubuntu), Linux Mobile (Phosh, Plasma Mobile)
* **License:** Open Source (GPLv3)
* **Downloads:** [Flathub](https://flathub.org/apps/org.kde.kasts) | [KDE Apps](https://apps.kde.org/kasts/)
* **Setup:** Go to Settings -> Sync -> Enable gPodder Sync -> enter Custom Server URL.
